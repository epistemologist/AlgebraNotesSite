# GT Basics
 - A **group** is a set with an operation $(G, \cdot)$  such that the operation is associative, there exists an element $e \in G$ such that $a \cdot e = e \cdot a = a \; \forall a \in G$ and all elements have inverses - if the operation is commutative, then the group is commutative/**abelian**
 - Given $g \in G$, the **order of $g$** (denoted $|g|$) is defined to be the minimum integer $k$ such that $g^k = e$ and $\infty$ if no such integer exists.
 - Examples
	 - $\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}, \mathbb{C}$ with addition, $\mathbb{R}^\times = \mathbb{R} - \{ 0 \}$ with multiplication
	 - ***dihedral group of order n***: for $n \ge 3$, let $D_{2n} = \{ \text{set of symmetries of regular n-gon}\}$
		 - note: $D_{2n} = \langle r,s | r^n = s^2 = 1,  sr^i = r^{-i} s\rangle$, $|D_{2n}| = 2n$
	- ***symmetric group***: given set $X$: $S_X = \{\sigma: X \to X | \sigma \text{ is bijection} \}$
		- if $|X| = n$ finite, then we may let $|X| = \{1 \cdots n\}$ and $S_{\{ 1 \cdots n\}} = S_n$ is the *symmetric group of degree n* with $|S_n| = n!$
		- note that any $\sigma \in S_n$ can be written as a *product of disjoint cycles*; if $\sigma = \sigma_1 \sigma_2 \cdots \sigma_k$ is a factorization of $\sigma$ into disjoint cycles, then $|\sigma| = \text{lcm}(|\sigma_1|, \cdots, |\sigma_k|)$
	- ***matrix groups****: given $n \in \mathbb{Z}^+$, and a field $F$, we can define $M_n(F)$ to be the set of $n \times n$ matrices with coeffs in $F$; $I_n$ to be the $n \times n$ identity matrix - then we let $$ GL_n(F) = \{A \in M_n(F) : A \text{ has an inverse} \} = \{A \in M_n(F) : \det(A) \ne 0 \}$$is the *general linear group of degree n* over F
	- ***quaternion group****: the set $Q_8 = \{ 1, \pm i, \pm j, \pm k \}$ endowed with a multiplication satisfying $$ \begin{aligned} i^2 = j^2 = k^2 &= -1 \\ ij = -k&, ji = -k \\ jk = i&, kj = -i \\ ki=j &, ik=-j \end{aligned}$$
- given two groups $(G, \star_G)$ and $(H, \star_H)$, a function $\phi: G \to H$ is a **homomorphism** if we have $\phi(x \star_G y) = \phi(x) \star_H \phi(y)$ for all $x,y \in G$; if $\phi$ is also a bijection, then it is an **isomorphism**
- given a group $G$, a nonempty subset $H \subseteq G$ is a **subgroup** of $G$ (denoted $H \le G$) if for all $x,y \in H$, we have $x^{-1} \in H, xy \in H$
	- note: we have that $xy^{-1} \in G$ is a sufficient condition for $H$ to be a subgroup
- given a group $G$ and nonempty $A \subseteq G$, the **centralizer of $A$ in $G$** is the set $$ C_G(A) = \{ g \in G: (\; ga = ag \; \forall a \in A \;)\;\}$$
- the **center** of a group $G$ is the set $$ Z(G) = C_G(G) = \{ g \in G: ga=ag \; \forall a \in G \}$$
	-  for any nonempty $A \subseteq G$, we have that $C_G(A), Z(G) \le G$
	-  let $H \le G$ be a subgroup - then $H\text{ abelian} \iff H \le C_G(H)$
- given nonempty $A \subseteq G$, the **normalizer** of $A$ in $G$ is the set $$N_A(G) = \{ g \in G : g A g^{-1} = A \} $$
	- we have $C_G(A) \le N_G(A) \le G$
	- if $|A| < \infty$, then $gAg^{-1} \subseteq A \iff gAg^{-1} = A$
- a group $G$ is **cyclic** if there exists an element $x \in G$ such that $G = \{ x^n : n \in \mathbb{Z} \}$; if such an $x$ exists, we denote $G = \langle x \rangle$ and $x$ is a **generator** of $G$.
	- note that any two cyclic groups of the same order are isomorphic - if $|G| = n < \infty$, then $G \cong \mathbb{Z}/n\mathbb{Z}$, otherwise $G \cong \mathbb{Z}$
	- every subgroup of a cyclic group is cyclic: let $H = \langle x \rangle$ be cyclic
		- if $|H| =\infty$, then $\langle x^a \rangle \le \langle x^b \rangle \iff b|a$
		- if $|H| =n$ finite, then for each positive divisor $d|n$, there exists a subgroup of order $d$ ($\langle x^{n/d}\rangle$)
- let $G$ be a group and let $S \subseteq G$.The **subgroup of $G$ generated by $S$** is defined as: $$ \langle S \rangle = \bigcap_{S \subseteq H \le G} H $$ i.e. the intersection of all subgroups of $G$ that contain the set $S$.
	- $\langle S\rangle$ is the smallest subgroup of $G$ that contains $S$ - moreover, we have $$ \begin{aligned} \langle S \rangle &= \left\{ \prod_{i=1}^n s_i^{e_i} : n \in \mathbb{Z}^+, s_i \in S, e_i \in \{\pm 1 \}\right\}  \\ &= \left\{ \prod_{i=1}^m s_i^{e_i} : m \in \mathbb{Z}^+, s_i \in S, e_i \in  \mathbb{Z}\right\} \end{aligned} $$
	- for example, for $n \ge 2$, we have $\{ (1,2), (1,2,3, \cdots, n) \}$ is a generating set for $S_n$
- some more on permutations
	- a 2-cycle is called a *transposition*, generally each $\sigma \in S_n$ can be written as a product of transpositions as we have each k-cycle $(a_1 a_2 \cdots a_m) = (a_1 a_2) (a_2 a_3) \cdots (a_{m-1} a_m)$ 
	- if $e = \tau_1 \cdots \tau_n$ is a product of transpositions, then $n$ must be even; from this we can define the **parity of a permutation**: if $\sigma\in S_n$ can be written as a product of an odd/even number of transpositions, we say that it is odd/even
	- the set $A_n$ of all even permutations in $S_n$ is a subgroup of $S_n$ and is called the **alternating group of order n**
	-  $A_n = \langle S_1 \rangle = \langle S_2 \rangle$ where  $S_1 = \{(i,j,k): i,j,k \text{ distinct}\}$ and $S_2 = \{ (1,2,k): 3 \le k \le n\}$
