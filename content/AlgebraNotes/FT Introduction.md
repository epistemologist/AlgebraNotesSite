# FT Introduction
 - Motivating example: complex conjugation is a *field automorphism*
	 - Note that if $z = a+bi \in \mathbb{C}$, we have that $\bar{z} = a-bi \in \mathbb{C}$ is the *conjugate* of $z$
	 - this is a field automorphism (i.e. we have that $\overline{z_1 + z_2} = \overline{z_1} +\overline{z_2}\;,\; \overline{z_1 \cdot z_2} = \overline{z_1} \cdot \overline{z_2}$ for all $z_1, z_2 \in \mathbb{C}$)
	 - moreover, if $f(x) = a_0 + a_1 x + \cdots + a_m x^m \in \mathbb{R}[x]$ and $f(z) = 0$, then $f(\bar{z}) = 0$ 
 - A **field** is a commutative ring with identity in which every nonzero element has a multiplicative inverse (Examples: $\mathbb{Z}_p$ for $p$ prime, $\mathbb{Q}$, $\mathbb{R}$, $\mathbb{C}$, $\mathbb{Q}(\sqrt{2}) = \{ a + b\sqrt2 : a,b \in \mathbb{Q}\}$, $\mathbb{R}[x] = \text{polynomials with real coeffs}$, $\mathbb{R}(x) = \text{rational functions with real coeffs}$ )
 - Recall for $R$ commutative ring and $I \triangleleft R$ ideal, we have $R/I$ field iff $I$ is maximal
	 - $I \triangleleft R$ is an *ideal* if $a,b \in I \implies a+b \in I$ and $a \in I, r \in R \implies a \cdot r, r \cdot a \in I$
	 - $I \triangleleft R$ is a *maximal ideal* if for any other ideal $J$ with $I \subseteq J$, we have either $J = I$ or $J = R$
 - In the case $R = F[x]$ for field $F$, every ideal is principal - i.e. of the form $(f(x))$
 - The **characteristic** of a field $F$ (denoted $\text{char}(F)$)is the smallest positive integer $p$ such that $p \cdot 1_F = 0$ if such a $p$ exists or 0 otherwise. For a field $F$, this is either 0 or $p$ prime - moreover, we have $$\begin{cases} \text{char}(F) = p \implies F \supseteq \mathbb{Z}_p \\ \text{char}(F) = 0 \implies F \supseteq \mathbb{Q} \end{cases}$$ (here, the field is an isomorphic copy and the one generated by the multiplicative identity of the field)
 - Let $K$ be a field containing the subfield $F$ - we say that $K$ is a **extension** of the field $F$; in this case, we have that $K$ is a *vector space* over $F$ and denote the **degree of the field extension** as $[K:F]$ to be the dimension of this vector space.
 - For a field $F$ and irreducible polynomial $p(x) \in F[x]$ of degree $n$, we have that the field $K = F[x] / (p(x))$ is an extension of $F$ which contains a root of $p(x)$. Moreover, we can explicitly describe $K$; letting $\theta = x \bmod (p(x)) \in K$, we have that the elements $1, \theta, \theta^2, \cdots, \theta^{n-1}$ form a basis of $K$ over $F$, so $[K:F] = n$ and $$ K = \{ a_0 + a_1 \theta +  a_2 \theta^2 + \cdots + a_{n-1}\theta^{n-1} : a_i \in F \}$$
 - Some examples
	 - $F = \mathbb{Q}[x] / (x^2-2)$ - given any $f(x) \in \mathbb{Q}[x]$, we have by the Division Theorem that $f(x) = q(x)(x^2-2) + r(x)$; we therefore have in $F$ that every element is of the form $a + bx$
	 - $F = \mathbb{Z}_2[x] / (x^2+x+1)$ - as $x^2+x+1$ irreducible over $\mathbb{Z}_2[x]$, this forms a field with 4 elements
 - An element $\alpha \in K$ is said to be **algebraic** over $F$ if $\alpha$ is the root of some non-zero polynomial $f(x) \in F[x]$. If $\alpha$ is not algebraic over $F$, it is said to be **transcendental** over $F$. If $\alpha$ algebraic over $F$, then there is a unique irreducible monic polynomial $f(x)$ which has $\alpha$ as a root - this is denoted the **minimal polynomial of $\alpha$ over $F$**.
 - If a field $K$ is generated by a single element $\alpha$ over $F$ (i.e. if $K = F(\alpha)$), then $K$ is said to be a **simple extension** of $F$ and the element $\alpha$ is called a **primitive element** for this extension. For a field $F$, irreducible $p(x) \in F[x]$ and an extension field $K$ containing a root $\alpha$ of $p(x)$; denote $F(\alpha)$ to be the subfield of $K$ generated over $F$ by $\alpha$. We have that $F(\alpha) \cong F[x] /(p(x))$
	 - Proof sketch: Take the map $$\begin{aligned} \phi: F[x] &\to F(\alpha) \\ p(x)&\mapsto p(\alpha) \end{aligned}$$ defined by sending $F$ to $F$ and sending $x$ to $\alpha$ and then extending to all of $F[x]$ via the fact that it is a ring homomorphism. We have $p(x) \in \ker{\phi}$  as $p(\alpha) = 0$ so we can define the induced homomorphism $\hat{\phi}: F[x]/(p(x)) \to F(\alpha)$ which is a field isomorphism.
 - Let $\alpha$ be algebraic over $F$ with minimal polynomial $f(x)$ - we have that $F(\alpha) \cong F[x] / (f(x))$
 - **Tower Rule for Field Extensions**: For field extensions $F \subseteq K \subseteq L$, we have $[L : F] = [L : K][K : F]$.
	 - Proof Sketch: for the finite case, if $\alpha_1 \cdots \alpha_m$ is a basis of $L$ over $K$ and $\beta_1 \cdots \beta_m$ is a basis of $K$ over $M$, then it can be shown that $\alpha_i \beta_j$ is a basis of $L$ over $F$
 - Some examples
	 - We calculate $[Q(2^{1/2}, 2^{1/3}):Q] = m$. Note that $m \le 6$ as we have $$ \begin{aligned} m = \underbrace{ [Q(2^{1/2}, 2^{1/3}): Q(2^{1/2})]}_{\substack{\le 3 \\ \text{min poly: $x^3-2$}}} \cdot \underbrace{ [Q(2^{1/2}: Q)]}_{=2}\end{aligned}$$ Since $[Q(2^{1/2}):Q]=2$ and $[Q(2^{1/3}:Q] = 3$, we have $m \le 6, 2 | m, 3 | m \implies m = 6$
	 - Similarly, if $[Q(2^{1/2}, 2^{1/4})] = m$, we have that $2|m, 4|m, m \le 8$; however we have that $Q(2^{1/2}, 2^{1/4}) = Q(2^{1/4})$, so we have that $m=4$ in this case
 - constructible numbers
	 - if lengths $a,b$ are constructible via compass/straightedge, we also have that $a \pm b, a \cdot b, a/b, \sqrt{a}$ are constructible; therefore the set of constructible numbers form a field
	 - we have that if $\alpha \in F \subset \mathbb{R}$ is constructible, then there is a series of field extensions $\mathbb{Q} =F_0 \subseteq F_1 \subseteq F_2 \subseteq \cdots \subseteq F_k$ where each $[F_{k+1}:F_k]$ is either 1 or 2; therefore we have that $[\mathbb{Q}(\alpha) : \mathbb{Q}] = 2^k$ for some integer $k$
	 - examples:
		 - doubling the cube is impossible as $[Q(2^{1/3}):Q] = 3$ is not a power of 2
		 - an angle $\theta$ is constructible only if $\cos \theta$ is constructible; since $\cos 20\degree$ has degree 3 over $\mathbb{Q}$, it is not constructible
		 - $\cos 3 \degree, \sin 3\degree$ constructible (see D&F)
 - Example Question: $\mathbb{Q}(\sqrt{2}+\sqrt{3}) = \mathbb{Q}(\sqrt{2}, \sqrt{3})$
	 - note that $\sqrt{2}+\sqrt{3} \in \mathbb{Q}(\sqrt{2},\sqrt{3}) \implies \mathbb{Q}(\sqrt{2}+\sqrt{3}) \subseteq \mathbb{Q}(\sqrt{2}, \sqrt{3})$ 
	 - *Method 1*: Solve $\begin{cases} \sqrt{2} = a + b(\sqrt{2}+\sqrt{3}) + c(\sqrt{2}+\sqrt{3})^2 + d(\sqrt{2}+\sqrt{3})^3 \\ \sqrt{3} =  a + b(\sqrt{2}+\sqrt{3}) + c(\sqrt{2}+\sqrt{3})^2 + d(\sqrt{2}+\sqrt{3})^3 \\ \end{cases}$ ; laborious
	 - *Method 2*: $$\begin{aligned} \sqrt{3}+\sqrt{2} &\in \mathbb{Q}(\sqrt{2}+\sqrt{3}) \\ &\implies (\sqrt{3}+\sqrt{2})^{-1} = \sqrt{3}-\sqrt{2} \in \mathbb{Q}(\sqrt{2} + \sqrt{3}) \\ &\implies (\sqrt{3}+\sqrt{2}) + (\sqrt{3}-\sqrt{2}) = 2\sqrt{3} \in \mathbb{Q}(\sqrt{2}+\sqrt{3})\end{aligned}$$and so $\sqrt{3} \in \mathbb{Q}(\sqrt{2}+\sqrt{3})$; a similar argument applies to $\sqrt{2}$
	 - *Method 3*: $$\begin{aligned} \sqrt{3}+\sqrt{2} &\in \mathbb{Q}(\sqrt{2}+\sqrt{3}) \\ &\implies (\sqrt{3}+\sqrt{2})^2 = 7+2\sqrt{6} \in \mathbb{Q}(\sqrt{2}+\sqrt{3}) \\ &\implies \sqrt{6} \in \mathbb{Q}(\sqrt{2}+\sqrt{3}) \\ &\implies \sqrt{6}(\sqrt{2}+\sqrt{3}) = 2\sqrt{3} + 3\sqrt{2} \in \mathbb{Q}(\sqrt{2}+\sqrt{3}) \\ &\implies (2\sqrt{2} + 3\sqrt{2}) - 2(\sqrt{2}+\sqrt{3}) = \sqrt{3} \in \mathbb{Q}(\sqrt{2}+\sqrt{3}) \end{aligned}$$ - a similar argument applies to $\sqrt{2}$.
	 - *Method 4*: argue based on dimension - we have the field extensions $\mathbb{Q} \subseteq \mathbb{Q}(\sqrt{2}+\sqrt{3}) \subseteq \mathbb{Q}(\sqrt{2}, \sqrt{3})$; note that $[\mathbb{Q}(\sqrt{2}+\sqrt{3}) : \mathbb{Q}] \le 4$ - we show that this degree is actually 4.
		 - $[\mathbb{Q}(\sqrt{2}+\sqrt{3}) : \mathbb{Q}]$ is the degree of the minimum polynomial of $\sqrt{2}+\sqrt{3}$; we have $$\begin{aligned} x &= \sqrt{2} + \sqrt{3} \\ &\implies (x - \sqrt{2})^2 = x^2 - 2\sqrt{2}x + 2 = 3 \\ &\implies (x^2-1)^2 = (2\sqrt{2}x)^2 \\ &\implies x^4 - 10x^2 + 1 = 0\end{aligned}$$
		 - show that this polynomial is irreducible (no integer roots so no linear factors, cannot be factored into 2 quadratics); therefore the degree is 4
 - the equation $x^m = 1$
	 - generally, the polynomial $x^m-1$ may be reducible; over $\mathbb{C}$, there are $m$ solutions to this equation - the elements $e^{2 \pi k i / m} = \cos{(2 \pi k/m)}+i \sin{(2 \pi k /m )}, k = 0, 1, \cdots, n-1$
	 - let $\Phi_m(x)$ be the minimal polynomial of $\xi=e^{2 \pi i / m}$; the *primitive* $m^{th}$ root of unity - we call this polynomial the $m^{th}$ **cyclotomic polynomial**
		 - we have that $\Phi_m(x) | x^m-1$ and more generally, $d|m \implies \Phi_d(x) | \Phi_n(x)$
		 - moreover, we have that $x^m-1 = \prod_{d | m} \Phi_d(x)$; this can be used to recursively calculate $\Phi_m(x)$ with base case $\Phi_1(x) = x-1$
			 - for example, for $m=10$, we have $$x^{10}-1 = \underbrace{ (x+1)}_{\Phi_2(x)}\underbrace{(x^4 - x^3 + x^2 - x + 1)}_{\Phi_10(x)}\underbrace{ (x-1)}_{\Phi_1(x)}\underbrace{(x^4+x^3+x^2+x+1)}_{\Phi_5(x)}$$
 - For a field $F$, an extension $K$ of $F$ is called a **splitting field** for the polynomial $f(x) \in F[x]$ if $f(x)$ factors completely into linear factors in $K$ (i.e. $f$ *splits completely*) and $f$ does not split completely in any proper subfield of $K$ containing $F$ (i.e. $K$ is the smallest field such that $f$ splits completely)
	 - note that for any polynomial $f(x) \in F[x]$, there exists a field extension $K$ such that $K$ is a splitting field for $f$
	 - for example, the field $\mathbb{Q}(\sqrt{2}, \sqrt{3})$ is a splitting field for the polynomial $(x^2-2)(x^2-3)$
	 - similarly, the splitting field of $x^3-2$ is *not* $\mathbb{Q}(\sqrt[3]{2})$ but $\mathbb{Q}(\sqrt[3]{2}, \sqrt[3]{2} \omega, \sqrt[3]{2}, \omega^2)= \mathbb{Q}(\sqrt[3]{2}, \sqrt{-3})$ where $\omega^3=1$ is a primitive 3rd root of unity
		 - note that $\sqrt[3]{2}$ has a min poly of $x^3-2$ and $\sqrt{-3}$ has a min poly of $x^2-3$; the total degree of the extension is therefore $2 \cdot 3 = 6$
	 - splitting fields can sometimes be smaller than expected - consider $p(x) = x^4+4$ over $\mathbb{Q}$; we have that $$\begin{aligned}x^4+4 &= x^4 + 4x^2 + 4 - 4x^2 = (x^2+2)^2 - 4x^2 \\ &= (x^2+2x+2)(x^2-2x+2)\end{aligned}$$ and so $p(x)$ admits roots $\pm 1 \pm i$; therefore the splitting field of $p(x)$ is only $\mathbb{Q}(i)$ which has dimension 2 over $\mathbb{Q}$
	 - note that if $f(x) \in F[x]$ has degree $n$; we have a chain of field extensions adjoining each root $F \subseteq F_1 \subseteq F_2 \subseteq \cdots F_n$. We have that $[F:F_1] \le n$ as the min poly has degree at most $n$; over $F_1$, $f(x)$ has at least a linear factor so $f(x)$ satisfies equation of degree $\le n-1$ and so on. Multiplying degrees of all the extensions gives us that the total degree is $\le n!$
- For a field $F$ and a polynomial $f(x) \in F[x]$, over a splitting field for $f(x)$, we have a factorization $f(x) = \prod_i(x-\alpha_i)^{n_i}$ for $\alpha_i$ in the splitting field and $n_i \ge 1$ for all $i$. Note that $\alpha_i$ is a *multiple root* if $n_i > 1$ and a *simple root* if $n_i = 1$.
- A polynomial over $F$ is called **separable** if it has no multiple roots
	- A polynomial $f(x) \in F[x]$ has a multiple root $\alpha$ iff $\alpha$ is also a root of $f'(x)$ (here, we take the derivative as a formal algebraic operation on polynomials); in particular, $f(x)$ is separable iff $\gcd(f, f') = 1$ 
	- Corollary: every irreducible polynomial over a field of char 0 is separable, any polynomial over such a field is separable iff it is the product of distinct irreducible polynomials
		- for example, over $F_p$, the polynomial $x^{p^n}-x$ has derivative $p^n x^{p^n-1} - 1 = -1$ - as the derivative has no roots, this polynomial has no multiple roots and is therefore separable
		- the polynomial $x^n-1$ has derivative $n x^{n-1}$; for any field of char not dividing $n$ (including 0) - this polynomial only has the root $0$ which is not a root of $x^n-1$; therefore over any such field, $x^n-1$ is separable and there are $n$ distinct roots of unity
- some results on fields of characteristic $p$
	- for a field $F$ with characteristic $p$, the $p^{th}$ power map $\phi(a) = a^p$ is an injective field homomorphism called the **Frobenius map**; moreover, in any such field, every element is a $p^{th}$ power
	- every irreducible polynomial over a finite field $F$ is separable; a polynomial in $F[x]$ is separable iff it is the product of distinct irreducible polynomials in $F[x]$
		- Proof Sketch: assume $p(x) \in F[x]$ irreducible - if $p(x)$ was inseparable, then $p(x) = q(x^p)$ for some $q(x) \in F[x]$; then use properties of Frobenius map to show that $p(x)$ is a $p^{th}$ power; contradicting assumption that $p$ was irreducible
- a note on finite fields (pg 549-550 of D&F)
	- over $F_p$, the polynomial $x^{p^n}-x$ is separable and therefore has $p^n$ roots. It can be shown that the set of roots of this polynomial is closed under addition, multiplication and inverses - this set (denote it $F$) is therefore the splitting field of $x^{p^n}-x$, and we have that $[F : F_p] = n$; therefore for each prime power $p^n$, there exists a field with $p^n$ elements
	- moreover, since this is a splitting field, it is unique up to isomorphism - therefore, there is one finite field for each prime power up to isomorphism
